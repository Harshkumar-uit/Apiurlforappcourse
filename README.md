# Apiurlforappcourse
Apiurlforappcourse
A REST API developed with Spring Boot and Maven to monitor course sales and traffic analytics. The API provides endpoints to check whether app courses are being sold and track the type and volume of traffic hitting the API.

Tech Stack:

Java, Spring Boot

Maven for build automation

Postman for API testing

Features:

Endpoints to verify course sale status

API traffic logging and monitoring

Scalable REST architecture
